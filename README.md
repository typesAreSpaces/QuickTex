# QuickTex

This tool automatically generates a minimal 
setup to quickly start working on a TeX project.

## Requirements

- A C++17 compiler and Make to build QuickTex (Linux or macOS).
- A TeX distribution with `pdflatex` and `latexmk` to build generated projects.
  Homework uses `titlesec`, `fancyhdr`, and `extramarks`; presentations use
  Beamer and `biblatex`; reports use `biblatex`. These are available in TeX Live.
  No personal `.sty` files are required.
- Git, with a configured commit identity, when enabling Git initialization.
- Python 3 to run the regression tests with `make test`.

## Build instructions

```
git clone https://github.com/typesAreSpaces/QuickTex.git
cd QuickTex
make
```

The binary `quicktex` will appear inside the bin folder
generated by the previous commands.

## Workflow

Execute `quicktex <project-name>`. The latter will generate
a directory named `<project-name>` including a main.tex
file, a figure folder, a Makefile containing rules to compile
the tex file main and editable tex files.

The destination must not already exist, even as an empty directory. Existing
files are never intentionally overwritten. Parent directories are created as
needed. Quote paths containing spaces or shell characters:

```
bin/quicktex "my project"
bin/quicktex /tmp/my-report r git
```

The optional second argument selects `b` (basic), `h` (homework), `p`
(presentation), or `r` (report). Adding a third argument enables Git
initialization and an initial commit. Generation or Git failures return a
nonzero exit status; files already generated are retained for inspection.

Inside the generated directory, execute `make` to compile `main.tex`.
Execute `make <project-name>.pdf` to build an up-to-date named copy. This name
uses only the last component of the project path, with characters other than
ASCII letters, digits, `.`, `_`, and `-` replaced by `_` (for example,
`my project` becomes `my_project.pdf`). `make clean` removes build outputs.

Execute `make watch` to use latexmk's continuous preview mode, which rebuilds
when project dependencies change. Press Ctrl-C to stop it.
